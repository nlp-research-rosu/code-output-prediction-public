# Experiments

The [benchmark catalog](../README.md#experiments-and-results) links the setup
and results of all five studies. Each experiment owns its cases, exact tasks,
collected attempts, measurements, analysis code, and final report.

`README.md` explains the design and reproduction commands. `reports/README.md`
is the complete analysis report. `reports/prediction-factor-analysis/README.md`
is the index of tables, figures, normalized data, and method.
